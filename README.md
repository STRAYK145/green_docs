# Зелёный город: документация пользователя

![Логотип фонда «Зелёный город»](logo.png)

**«Зелёный город»** — благотворительный фонд озеленения. Мы сажаем деревья и кустарники в парках, дворах и вдоль улиц, а жители помогают нам их сажать и растить.

Мобильное приложение фонда позволяет записаться на посадку, найти любое дерево на карте и следить за тем, как оно растёт. У каждого посаженного дерева есть **собственный номер**, поэтому судьба каждого саженца отслеживается от посадки до взрослого дерева.

<u>Важно:</u> фонд работает на добровольной основе. Участие в посадках бесплатное, денежные сборы и платежи в приложении не предусмотрены.
