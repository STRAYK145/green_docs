# Нумерация деревьев

![Табличка на дереве с номером и QR-кодом](tag.png)

У каждого дерева, которое сажает фонд, есть **уникальный номер**. Он записывается в реестр и наносится на небольшую табличку, закреплённую на стволе. На табличке также есть QR-код: если навести на него камеру приложения, откроется карточка дерева.

## Как устроен номер

Номер состоит из четырёх частей, разделённых дефисами. Пример:

```
ZG-CEN-2026-000125
```

Расшифровка:

1. `ZG`: префикс фонда («Зелёный город»);
2. `CEN`: код района города (например, центральный);
3. `2026`: год посадки;
4. `000125`: порядковый номер дерева в этом районе за этот год.

То есть `ZG-CEN-2026-000125` — это 125-е дерево, посаженное в центральном районе в 2026 году.

## Правила нумерации

- номер присваивается в момент посадки и больше не меняется;
- порядковый номер растёт на единицу с каждым новым деревом в районе и обнуляется в начале нового года;
- номер никогда не используется повторно, даже если дерево погибло;
- если дерево пересажено в другое место, оно сохраняет свой номер, а в карточке появляется запись о переносе.

## Какие данные хранятся под номером

Для каждого номера в реестре создаётся запись. Пример (упрощённо):

```
{
  "id": "ZG-CEN-2026-000125",
  "species": "Липа мелколистная",
  "planted": "2026-04-18",
  "location": "55.7558, 37.6173",
  "status": "Приживается"
}
```

## Как найти дерево по номеру

1. Откройте раздел **«Реестр деревьев»**.
2. Нажмите на значок поиска.
3. Введите номер дерева или отсканируйте QR-код с таблички.

<u>Подсказка:</u> достаточно ввести часть номера, например `2026-000125`, приложение найдёт подходящие деревья.
